☁️ Sinkronisasi Google Sheets (Apps Script)

Website ini dilengkapi backend Google Apps Script sehingga seluruh materi slide, kumpulan soal kuis guru, serta rekap nilai siswa dapat disimpan langsung ke Google Spreadsheet secara gratis tanpa biaya server.

Petunjuk Singkat untuk Guru:
  1. Buka file Code.gs yang sudah disediakan di folder proyek ini.
  2. Buat Google Spreadsheet baru di Drive Anda, pilih menu Ekstensi > Apps Script, lalu salin seluruh isi Code.gs.
  3. Klik Deploy (Terapkan) > New Deployment (Penerapan Baru), pilih Web App, atur akses ke Anyone (Siapa Saja).
  4. Salin URL hasil deploy ke dalam kotak input di atas!
